# Installer Emozio sur l'iPhone (iOS 26)

L'installation se fait deux fois : d'abord l'adresse de test `dev--<site>.netlify.app`, nommée « Emozio TEST », puis l'adresse définitive, nommée « Emozio ».

1. Ouvrir l'adresse dans **Safari**, toucher « ••• », puis « Partager », puis « Sur l'écran d'accueil ».
2. Vérifier que **« Ouvrir comme app web » est activé**. Nommer l'icône, puis toucher « Ajouter ».
3. Ouvrir l'icône une fois avec du réseau. Attendre que Réglages affiche « Hors ligne : prêt ».
4. Placer « Emozio » dans le Dock.

## À savoir

- **Les données vivent dans l'app installée**, pas dans Safari. Ouvert dans Safari, Emozio n'affiche que ce guide.
- **Supprimer l'icône supprime les données.** Toute réinstallation se fait dans cet ordre : exporter une sauvegarde, supprimer l'icône, réinstaller, importer.
- **Sauvegardes** : Réglages, puis Sauvegarde, puis Exporter. Dans la feuille de partage, choisir « Enregistrer dans Fichiers », puis iCloud Drive, dossier « Emozio ». Une sauvegarde plus ancienne, du temps où l'app s'appelait « Carnet » (dossier « Carnet », fichier `carnet-sauvegarde-…`), s'importe telle quelle.
- **Diagnostic** : dans Réglages, un appui long sur le numéro de version.
