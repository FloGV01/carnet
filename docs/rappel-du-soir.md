# Rappel du soir (app Raccourcis, iOS 26)

L'app n'envoie aucune notification. Les rappels sont des automatisations de l'app Raccourcis, désactivables à tout moment.

1. Ouvrir **Raccourcis**, onglet **Automatisation**, puis toucher « + ».
2. Choisir **Heure de la journée** : 21:00, tous les jours.
3. Choisir **Exécuter immédiatement**, puis désactiver la notification d'exécution.
4. **Nouvelle automatisation vierge**, puis ajouter l'action **Afficher une notification**, avec le texte : « Le soir dans Emozio, si tu veux. »

## Émotion du moment (si tu veux)

Les heures se choisissent dans Réglages › Rappels. Pour chacune, refaire les mêmes 4 étapes avec cette
heure-là et le texte : « Émotion du moment, si tu veux. » Ensuite, ouvrir Emozio et toucher « Émotion », en bas.
Les heures ne servent qu'à ce pas-à-pas : rien dans l'app ne compare les heures aux relevés.

## Bon à savoir

- **Pas d'action « Ouvrir les URL ».** Elle ouvrirait Safari, dont le stockage est vide. L'icône Emozio est dans le Dock.
- **Mode Concentration** : s'il est actif à 21:00, autoriser Raccourcis dans ce mode.
- **Couper le rappel** : désactiver l'automatisation dans Raccourcis.
- Le rappel s'affiche même si la soirée est déjà remplie. L'app et Raccourcis ne communiquent pas, c'est voulu.
