# Emozio

App web personnelle de suivi quotidien, installable sur l'écran d'accueil de l'iPhone. Toutes les données restent sur le téléphone (IndexedDB). Elle fonctionne hors ligne et n'a aucun serveur.

- Développement : voir `CLAUDE.md`.
- Installation sur l'iPhone : `docs/installation-iphone.md`.
- Rappel du soir : `docs/rappel-du-soir.md`.
- Déploiement : `docs/deploiement.md`.
